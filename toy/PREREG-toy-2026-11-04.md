## 1. Design (frozen here)

- **Bases:** SmolLM2-360M (Apache-2.0) primary; pythia-410m (Apache-2.0) fallback. No Chinese-origin model. Base revision SHA recorded at download. The gate (F-T1) is run on both; training uses SmolLM2 if it passes, else pythia if it passes, else STOP.
- **Full fine-tune only** (no LoRA/adapters: a low-rank update manufactures a smooth low-rank displacement, the artefact that killed the pilot's instrument). Optimiser AdamW(0.9, 0.95), weight decay 0, fp32 master weights, no dropout in either config (so the seed controls only data order and, for GRPO, sampling; recorded).
- **Seeds 0,1,2.** Seed controls: shuffle order of the fixed slice into batches, and (GRPO) rollout sampling and prompt order. The data SLICE, hyper-parameters and the reference log-probs are identical across seeds.
- **SFT:** slice = 500,000 packed training tokens (sequences of 512, ~977 sequences) from `allenai/tulu-3-sft-mixture`: one parquet shard fixed by name, rows selected by `numpy.random.default_rng(20261104)` permutation, English-only filter (>= 95% ASCII characters), chatml formatting `<|im_start|>role\n...<|im_end|>\n`, loss on assistant tokens only. Slice hash = sha256 of the concatenated token-id array, recorded in `toy/data/slices.json`. lr 2e-5 cosine to 10%, warmup 5 steps, effective batch 8 sequences, one epoch.
- **DPO:** slice = first 1000 pairs (after the same English filter and a cap of 256 tokens on chosen and on rejected incl. prompt) of a fixed-seed permutation of a fixed shard of `allenai/llama-3.1-tulu-3-8b-preference-mixture`; slice hash recorded. Own implementation of the sigmoid DPO loss (Rafailov 2023), beta 0.1, reference = the base, reference log-probs computed once and cached (identical for all seeds), lr 1e-6 constant after 3 warmup steps, effective batch 16 pairs, one epoch (~62 steps).
- **GRPO (RLVR):** TRL `GRPOTrainer` if it runs on this stack (torch 2.15 CPU, transformers 5.22); otherwise an own minimal GRPO loop (group-normalised advantages, no KL, no reference model), reported as a deviation. Prompts: 2000 locally generated problems `"{a} {op} {b} ="`, op in {+,-,x}, a,b uniform 2-3 digit (generator seed 12345, fixed; slice hash recorded). Reward 1 if the first integer in the completion equals the answer, else 0. 8 prompts x 8 generations per step, max 8 new tokens, temperature 1.0, lr 1e-6, 150 steps fixed. Wall budget <= 4 h per seed: if seed 0 does not finish its 150 steps in 4 h the arm is stopped and reported; seeds 1,2 run only if seed 0 finished within 4 h.
- **Throughput rule (arithmetic, T0):** 6ND at 100 GFLOP/s planning (parent design benchmark) gives ~22 ms/token; SFT 500k tokens ~ 3 h, DPO ~ 500k tokens ~ 3 h per seed. **Deviation owned:** the brief said ~1M SFT tokens (~6 h per seed, ~18 h for three); I halved it to 500k for wall time. If the measured step time projects > 2x this plan, I stop that arm, amend this file by addendum (before any extraction of trained weights), and say so; no silent change.
- **Cap/limits:** every model job under `systemd-run --user --scope --quiet -p MemoryMax=16G -p MemorySwapMax=0 -- env OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 nice -n 10 uv run ...`, `rtp.cap.require_cap()` first in each script; one training or extraction job at a time; VmHWM recorded per run. Final weights saved to `/mnt/e/toy-residency/` only, deleted after extraction.

## 2. Frozen inputs and statistics

- **Entities:** the pilot's frozen CSVs (`../data/entities/`), unchanged, restricted to survivors of the cross-tokenizer check under the toy tokenizer (all 8 templates tokenise as prefix + name, name <= 4 tokens, the pilot's `build_prompts` assertion). If geography survivors < 300 or C1 survivors < 300: STOP, report. C1 nouns are matched to geography by `matched_geo`; the paired set is the pairs where both survive.
- **Frozen from the base only, before any trained run is opened:** l*, per set m (gap rule over 100 bootstrap spectra, range [4,20], as pilot step 4), r (90% PCs capped n//10), written to `toy/frozen.json` with the base SHA.
- **Per run** (stage s, seed i): H_{s,i} (n x d) per set. D_{s,i} = H_{s,i} - H_b (centred).
- **‖D_stage‖/‖H‖:** D_stage = mean_i H_{s,i} - H_b (seed-mean stage displacement), ‖.‖ Frobenius, H = centred H_b. **‖D_seed‖/‖H‖:** D_seed(i,j) = H_{s,i} - H_{s,j} (same stage), median over the 3 pairs. Both reported for every set; the primary set is geography. Secondary (noise-floor-aware): under pure seed noise E‖D_stage‖^2 = ‖D_seed‖^2/6, so the excess ‖D_stage‖^2 - ‖D_seed‖^2/6 is reported.
- **Smoothness:** kernel-ridge held-out R^2 of D on H_b with the step-14 recipe (RBF, bandwidth = sqrt of the median pairwise squared distance, lambda by 5-fold CV over logspace(-6,2,17), 80/20 split, split seed 5), for D_stage and for each D_seed (median reported).
- **Enrichment:** R = D - P_r P_r^T D (P_r = top-r PCs of the centred base), f_low(R) on the base graph (self-tuning kernel, alpha=1, low band modes 2..m+1), exactly `rtp.measures.f_low_gram`. **E(set, stage) = f_low(R_stage) / median over the 3 seed pairs of f_low(R_seed(i,j))**. E > 1 means the stage displacement is more low-band (smoother on the entity graph) than the seed-to-seed noise. This is a ratio of colours, scale-free.
- **Bootstrap (B = 1000 real data, B = 200 calibration):** each draw = an 80% entity subsample without replacement (graph, P_r, U rebuilt from the base subsample, m and r frozen; paired sets use the paired subsample) and a resample (with replacement, size 3) of the 3 seed pairs for the denominator median. 95% percentile interval. With 3 seeds the pair resampling is coarse (3 pairs, dependent through shared seeds); the interval is T3.
- **Entity-minus-control:** primary Delta = E(geo) - E(C1 nouns) on the paired subsample (Zipf-matched controls); secondary (non-voting) E(figures) - E(C2 nonce) unpaired. CI as above.
- **Calibration (planted rewiring, step-15 analogue with the seed band as the null):** for each stage and each ordered choice of a seed pair (a,b) with remaining seed c: pseudo-stage displacement N = (D_a - D_b)/sqrt(2) (pure seed noise, no stage-common signal), planted D_syn = sqrt(1-s) N/‖N‖ + sqrt(s) W/‖W‖ rescaled to ‖N‖, on geography only; W = U_low M (low modes 2..m+1 of the base geography graph, M Gaussian), centred; share s in {0, 0.05, 0.10, 0.20} of ‖D‖^2 before PC removal. Controls (C1 nouns, paired) get the unplanted N from the same pair. The seed band for the pseudo-stage is the two pairs not equal to (a,b) (only 2 pairs available; dependent). 3 stages x 3 pairs x 3 rewiring seeds = 27 replicates per s (fewer if GRPO is absent). **Detection** = 95% CI of Delta excludes 0 from above. Power = detection rate at s > 0; size = detection rate at s = 0.

## 3. Falsifiers

- **F-T1 (gate):** base geography 5-fold ridge R^2 of the 3-D unit position (cos lat cos lon, cos lat sin lon, sin lat; template-mean last-token vectors at l*; pilot `ridge_r2`, seed 0) < 0.5, or survivors below the floors above, or the pilot battery fails, or closure fails => no entity graph at this size; STOP and report the number. Run on both bases; report both.
- **F-T2 (seed-dominated):** median over stages (those with >= 2 seeds) of ‖D_stage‖/‖H‖ <= ‖D_seed‖/‖H‖ (geography) => the stage test has no power at this scale; reported as the result.
- **F-T3 (calibration):** at s = 0.10 the power of the Delta test is < 0.8, or the size at s = 0 is > 0.10 => the entity-versus-control enrichment is not separable from zero on the planted-rewiring calibration; no enrichment verdict is read.
- **F-T4 (pipeline, not hypothesis):** pilot battery failure, closure failure, training divergence (non-finite loss), weights identical to the base. Then nothing from that run is reported as a result.

**Pass** (what P1-P3 of the pilot would gain), only if none of F-T1..F-T4 fires: (P1-S analogue) SFT: Delta CI > 0, i.e. imitation displaces the entity graph toward low modes more than seed noise does, controls less; (P1-R analogue) GRPO: Delta CI <= 0 or E(geo) <= 1 with power at s=0.10 >= 0.8, i.e. reward displacement is not more low-band than seed noise; (P2 analogue) not tested (cost measures not preregistered here); (P3) not testable at one size. A pass is a shape result on one 360M model with 3 seeds (T3); it is not evidence for the hypothesis at residency scale. DPO is measured and reported, not voting (as in the parent). Quoting any enrichment number when F-T3 fires is forbidden.
